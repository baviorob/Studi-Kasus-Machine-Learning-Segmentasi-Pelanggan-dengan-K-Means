
Studi Kasus Machine Learning: Segmentasi Pelanggan dengan K-Means
Ringkasan
Proyek latihan ini menerapkan unsupervised learning menggunakan algoritma K-Means untuk mengelompokkan pelanggan berdasarkan usia, pendapatan tahunan, skor belanja, jumlah transaksi, rata-rata belanja, dan lama berlangganan.

Topik diambil dari materi seminar tentang machine learning: preprocessing data, clustering, evaluasi model, interpretasi hasil, dan tantangan kualitas data.

File
Untitled4.ipynb: notebook untuk Google Colab.
dataset_dummy_segmentasi_pelanggan.csv: dataset sintetis untuk latihan.
Cara menjalankan
Buka https://colab.research.google.com/.
Upload Untitled4.ipynb.
Jalankan sel secara berurutan.
Saat diminta, upload dataset_dummy_segmentasi_pelanggan.csv.
Notebook mengeksplorasi data, membersihkan nilai kosong, menstandardisasi fitur, membandingkan nilai K, melatih K-Means, memvisualisasikan hasil, lalu mengekspor CSV hasil.
Batasan dan etika
Dataset adalah data dummy/sintetis, bukan data pelanggan nyata. Cluster bukan label kebenaran dan tidak boleh langsung digunakan untuk keputusan yang berdampak pada individu. Untuk penggunaan nyata, periksa kualitas dan representasi data, privasi, bias, serta validasi manfaat segmentasi.
